## Rules 100-104. Four of the five were written by the last four rounds.

* **100** — vertical text is quantised to ~1.0 device px. Sweep the plateau and
  put your value at its **centre**.
* **101** — supply a REFUTING measurement: a landmark with a tolerance, takeable
  before any band is scored, that comes out wrong if you are wrong.
* **102** — order matters, and a self-authored instrument is not privileged. When
  two estimators disagree, add a **third sharing no parameter with either**.
* **103** — **two estimators agreeing is not two independent estimators.** The
  ink centroid and a whole-profile SSD both mis-read a bottom-anchored height
  deficit as a translation. **Paired edge crossings** resolve it: same direction
  = translation, opposite = size, one landed and one off = both.
* **104, and it invalidated a class of earlier measurement** — `runCss` emits
  `scaleX(s) scaleY(sy) translate(tx,ty)` at `transform-origin: 0 0`, mapping
  local y to `sy*(y+ty)`. **`sy` moves the baseline as well as resizing**, and
  `ty` is multiplied by it. Six runs read argmin on a bare `sy` sweep and *all
  six* gained once `ty` moved with them. Before sweeping any parameter, read the
  emitter and ask **what else that parameter moves**.
