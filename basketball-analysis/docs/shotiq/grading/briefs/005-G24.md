## Read rules 93-101 first. Six of them were written by the last six rounds.

* **93** — a prescription carries a PIVOT, and the pivot is a property of the
  emitter, not the image. `runCss` emits `scaleX scaleY translate` with
  `transform-origin: 0 0`, so `ty` is MULTIPLIED by `sy` and the translate lands
  after both scales. An **x-positioned** run pivots on the element's LEFT edge; a
  **cx-positioned** run (`left: cx - w/2`, `text-align: center`) pivots on `cx`.
  Read `runCss`, `markBox`, `hitbox` and `Icon` before converting any measurement
  into a prescription, and **state the pivot you assumed**.
* **95** — a sub-pixel nudge is itself subject to the rounding it corrects.
  Express corrections as RELATIVE quantities inside the artefact being corrected
  wherever the choice exists.
* **97** — there is a re-rasterisation cutoff at roughly 2.4%, and it is bounded
  to SIZE changes only. Two `sy` values inside it were reverted because they were
  measuring nothing.
* **100** — vertical text position is quantised to 1.0 device px. Every body run
  is already within 0.37 px of the excess-splitting optimum, i.e. inside the
  plateau. Do not prescribe a vertical text nudge without showing it crosses a
  quantisation boundary.
* **101, and its example was WRONG until round 38 corrected it** — proving a
  declaration applied to element X is not proving it applied to the element that
  PAINTS. Round 37 put `vectorEffect` on the `<g>`; `vector-effect` is **not
  inherited**, so the paths kept `none` and the round measured a null experiment
  while believing it had measured a mechanism.
